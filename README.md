# Karriärum 2026 – Möbeldesign

Checklista och karta över Karriärum 2026 med filter per utbildning.
Allt ligger i `index.html`. Bockar och anteckningar sparas i webbläsaren.

## Lägga ut på GitHub Pages

1. Skapa ett nytt repo, t.ex. `karriarum-2026`.
2. Ladda upp alla filer i den här mappen (`index.html`, `manifest.webmanifest`, `sw.js`, ikonerna).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)`.
4. Efter en minut ligger sidan på `https://<användarnamn>.github.io/karriarum-2026/`.

På mobilen: öppna länken och välj *Lägg till på hemskärmen*. Efter första besöket fungerar den även utan nät.
